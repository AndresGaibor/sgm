# tFixedFlowInput Standard properties

These properties are used to configure tFixedFlowInput running in the Standard Job framework.

The Standard tFixedFlowInput component belongs to the Misc family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Schema and Edit<br>Schema | A schema is a row description, it defines the number of fields<br>that will be processed and passed on to the next component. The<br>schema is either built-in or remote in the Repository.<br><br>Click Edit<br>schema to make changes to the schema. If the current schema is of the Repository type, three options are available:<br><br><ul> <li> <p> <span>View schema</span>: choose this                option to view the schema only.</p> </li> <li> <p> <span>Change to built-in property</span>:                choose this option to change the schema to <span>Built-in</span> for local changes.</p> </li> <li> <p> <span>Update repository connection</span>:                choose this option to change the schema stored in the repository and decide whether                to propagate the changes to all the Jobs upon completion.</p> <p>If you just want to                propagate the changes to the current Job, you can select <span>No</span> upon completion and choose this schema metadata                again in the <span>Repository Content</span>                window.</p> </li> </ul><br><br><br>Built-in: The schema will be created and<br>stored locally for this component only. For more information about a component<br>schema in its Basic settings tab, see [Basic settings tab](https://help.qlik.com/talend/r/en-US/8.0/studio-user-guide/basic-settings-tab).<br><br><br>Repository: You have already created the<br>schema and stored it in the Repository, hence can be reused in various projects<br>and Job designs. For more information about a component schema in its<br>Basic settings tab, see [Basic settings tab](https://help.qlik.com/talend/r/en-US/8.0/studio-user-guide/basic-settings-tab). |
| Mode | From the three options, select the mode that you want to<br>use.<br><br><br>Use Single Table : Enter the data<br>that you want to generate in the relevant value field.<br><br><br>Use Inline Table : Add the row(s)<br>that you want to generate.<br><br><br>Use Inline Content : Enter the data<br>that you want to generate, separated by the separators that you have<br>already defined in the Row and<br>Field Separator fields. |
| Number of rows | Enter the number of lines to be generated. |
| Values | Between inverted commas, enter the values corresponding to the<br>columns you defined in the schema dialog box using the Edit schema button. |

## Usage

| Usage guidance | Description |
| --- | --- |
