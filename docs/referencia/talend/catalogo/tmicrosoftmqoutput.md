# tMicrosoftMQOutput

Writes a defined column of given inflow data to Microsoft message queue (only support String type).

For further information, see [https://help.talend.com/r/en-US/8.0/studio-user-guide/messaging-brokers-supported-by-talend-messaging-components](https://help.qlik.com/talend/r/en-US/8.0/studio-user-guide/messaging-brokers-supported-by-talend-messaging-components).

## tMicrosoftMQOutput Standard properties

These properties are used to configure tMicrosoftMQOutput running in the Standard Job framework.

The Standard tMicrosoftMQOutput component belongs to the Internet family.

The component in this framework is available in all Talend products.

Information noteNote: To use this component:

* If you are using a 64-bit platform, download the 64-bit version of MsmqJava.dll and put it in the Temp folder (for example, C:\Users\talend\AppData\Local\Temp\). You can download the file at https://github.com/ikerlan2015/MsmqJava .
* Make sure VC++ 2013 redistributables (64-bit) is installed.
* If you are using a queue that is of a private type, make sure the Microsoft Message Queue (MSMQ) feature is enabled. See [Installing Message Queuing (MSMQ)](https://docs.microsoft.com/en-us/dotnet/framework/wcf/samples/installing-message-queuing-msmq) for information about enabling MSMQ for queues that are of private types.

## Basic settings

| Properties | Description |
| --- | --- |
| Property type | <ul> <li> <p>Either <span>Built-in</span> or <span>Repository</span>. </p> </li> <li> <p> <span>Built-in</span>: No property data stored								centrally. Enter properties manually</p> </li> <li> <p> <span>Repository</span>: Select the repository								file where properties are stored. The fields that come after are								pre-filled in using the fetched data.</p> </li> </ul> |
| Host | Type in the Host name or the IP address of the host server. |
| Queue | Type in the name of the queue which you want write a given message<br>in. This queue can be created automatically on the fly if it does<br>not exist then. |
| Queue type | Select a Microsoft message queue type from the drop-down list.<br><br><ul> <li> <p> <span>Private												Non-Transaction</span>: a private											non-transactional queue.</p> </li> <li> <p> <span>Private Transaction</span>:											a private transactional queue.</p> </li> <li> <p> <span>Public												Non-Transaction</span>: a public											non-transactional queue.</p> </li> <li> <p> <span>Public Transaction</span>: a											public transactional queue.</p> </li> </ul><br><br>For more information about Microsoft message queue types, see<br>http://msdn.microsoft.com/en-us/library/ms706878%28v=vs.85%29.aspx. |
| Message column | Select the column as message to be written to Microsoft message<br>queue. The selected column must be of String type. |
| Die on error | This check box is cleared by default, meaning to skip the row on<br>error and to complete the process for error-free rows. |
