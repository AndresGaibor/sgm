# tMysqlColumnList

Iterates on all columns of a given Mysql table and lists column names.

## tMysqlColumnList Standard properties

These properties are used to configure tMysqlColumnList running in the Standard Job framework.

The Standard tMysqlColumnList component belongs to the Databases family.

The component in this framework is available in all Talend products.

Information noteNote: This component is a specific version of a dynamic database connector. The properties related to database settings vary depending on your database type selection. For more information about dynamic database connectors, see [DB Generic components](https://help.qlik.com/talend/r/en-US/8.0/components/db-generic/db-generic-component).

## Global Variables

| Variables | Description |
| --- | --- |
| Global Variables | COLUMN\_NAME: the name of the column<br>currently iterated upon. This is a Flow variable and it returns a string.<br><br><br>DATA\_TYPE: the data type of the column currently iterated upon. This is a<br>Flow variable and it returns a string.<br><br><br>COLUMN\_DEFAULT: the default value of the<br>column currently iterated upon. This is a Flow variable and it returns a string.<br><br><br>IS\_NULLABLE: nullability of the column currently uiterated upon. This<br>is a Flow variable and it returns YES if the column allows NULL; otherwise, NO.<br><br><br>COLUMN\_KEY: the key indicator of the column currently iterated upon.<br>This is a Flow variable and it returns a string if the column is set to Key; otherwise<br>it returns nothing.<br><br><br>CHARACTER\_MAXIMUM\_LENGTH: the maximum length in number<br>of characters of the column currently iterated upon. This is a Flow variable, and it<br>returns a numeric string for binary or character data types and NULL for other<br>types.<br><br><br>NUMERIC\_PRECISION:<br>the data precision of the column currently iterated upon. This is a Flow variable, and<br>it returns a numeric string for approximate numeric data, exact numeric data, integer<br>data, or monetary data and NULL for other data types.<br><br><br>NUMERIC\_SCALE: the scale in<br>digits allowed in the column currently iterated upon. This is a Flow variable, and it<br>returns a numeric string for approximate numeric data, exact numeric data, integer data,<br>or monetary data and NULL for other data types.<br><br><br>NB\_COLUMN: the number of columns iterated<br>upon so far. This is an After variable and it returns an integer.<br><br><br>ERROR\_MESSAGE: the error message generated by the<br>component when an error occurs. This is an After variable and it returns a string. This<br>variable functions only if the Die on error checkbox is<br>cleared, if the component has this checkbox.<br><br>A Flow variable functions during the execution of a component<br>while an After variable functions after the execution of the component.<br><br>To fill up a field or expression with a variable, press Ctrl+Space to access the variable list and choose the variable to use from<br>it.<br><br>For more information about variables, see [Using contexts and variables](https://help.qlik.com/talend/r/en-US/8.0/studio-user-guide/contexts-and-variables). |

## Usage

| Usage guidance | Description |
| --- | --- |
| **Usage rule** | This component is to be used along with Mysql components,<br>especially with tMysqlConnection. |
| Dynamic settings | Click the [+] button to add a row in the table<br>and fill the Code field with a context<br>variable to choose your database connection dynamically from multiple<br>connections planned in your Job.
