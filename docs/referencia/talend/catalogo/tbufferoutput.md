# tBufferOutput

Collects data in a buffer in order to access it later via webservice for example.

tBufferOutput has been designed to be exported as Webservice in order to access data on the web application server directly. For more information, see [Creating a Welcome Action Process](https://help.qlik.com/talend/r/en-US/8.0/studio-user-guide/creating-welcome-action-process).

## tBufferOutput Standard properties

These properties are used to configure tBufferOutput running in the Standard Job framework.

The Standard tBufferOutput component belongs to the Misc family.

The component in this framework is available in all Talend products.
