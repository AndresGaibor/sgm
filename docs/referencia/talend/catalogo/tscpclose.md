# tSCPClose

Closes a connection to an SCP protocol.

tSCPClose closes a connection to a fully encrypted channel.

## tSCPClose Standard properties

These properties are used to configure tSCPClose running in the Standard Job framework.

The Standard tSCPClose component belongs to the Internet family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Component list | If there is more than one connection in the current Job, select<br>tSCPConnection from the<br>list. |
