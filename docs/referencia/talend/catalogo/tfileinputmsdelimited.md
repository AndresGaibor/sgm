# tFileInputMSDelimited

Reads the data structures (schemas) of a multi-structured delimited file and sends the fields as defined in the different schemas to the next components using Row connections.

## tFileInputMSDelimited Standard properties

These properties are used to configure tFileInputMSDelimited running in the Standard Job framework.

The Standard tFileInputMSDelimited component belongs to the File family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Multi Schema Editor | The Multi Schema Editor helps<br>to build and configure the data flow in a multi-structure delimited<br>file to associate one schema per output.<br><br>For more information, see [The Multi Schema Editor](https://help.qlik.com/talend/en-US/components/8.0/ms-delimited/multi-schema-editor). |
| Output | Lists all the schemas you define in the Multi Schema Editor, along with the related record<br>type and the field separator that corresponds to every schema, if<br>different field separators are used. |
| Die on error | Select this check box to stop the execution of the Job when an<br>error occurs. Clear the check box to skip the row on error and<br>complete the process for error-free rows. |

## Advanced settings

| Properties | Description |
| --- | --- |
| Trim all column | Select this check box to remove leading and trailing whitespaces<br>from defined columns. |
| Validate date | Select this check box to check the date format strictly against<br>the input schema. |
| Advanced separator (for numbers) | Select this check box to modify the separators used for<br>numbers:<br><br><br>Thousands separator: define<br>separators for thousands.<br><br><br>Decimal separator: define<br>separators for decimals. |
| tStatCatcher Statistics | Select this check box to gather the Job processing metadata at a<br>Job level as well as at each component level. |
