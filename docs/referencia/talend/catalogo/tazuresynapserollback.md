# tAzureSynapseRollback

Cancels the transaction commit in the connected Azure SQL Data Warehouse database to prevent partial transaction commit if an error occurs.

## tAzureSynapseRollback Standard properties

These properties are used to configure tAzureSynapseRollback running in the Standard Job framework.

The Standard tAzureSynapseRollback component belongs to two families: Cloud and Databases.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Component List | Select the tAzureSynapseConnection<br>component in the list if more than one connection are planned for the<br>current Job. |
| Close Connection | This check box is selected by default. It allows you to close the database connection once the operation is done. Clear this check box to continue to use the selected connection once the component has performed its task. |

## Advanced settings

| Properties | Description |
| --- | --- |
| tStatCatcher Statistics | Select this checkbox to gather the Job processing metadata at the Job level<br>as well as at each component level. |

## Global Variables

| Variables | Description |
| --- | --- |
| ERROR\_MESSAGE | The error message generated by the component when an error<br>occurs. This is an After variable and it returns a string. |
