# tCloudStop

Changes the status of a launched instance on Amazon EC2 (Amazon Elastic Compute Cloud).

This component accesses the cloud provider to be used (Amazon EC2) and suspends, resumes or terminates given instance(s).

## tCloudStop Standard properties

These properties are used to configure tCloudStop running in the Standard Job framework.

The Standard tCloudStop component belongs to the Cloud family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Access key and Secret key | Enter or paste the access key and the secret key required by<br>Amazon to authenticate your requests to its web services. These<br>access credentials are generated from the Security Credential view<br>of your Amazon account page.<br><br>To enter the secret key, click the [...]<br>button next to the secret key field, and then in the pop-up dialog box enter the password<br>between double quotes and click OK to save the<br>settings. |
| Cloud provider | Select the cloud provider to be used. |
| Action | Select the action you need tCloudStop to take in order to change the status of<br>a given instance. This action may be:<br><br><ul> <li> <p> <span>Suspend</span> </p> </li> <li> <p> <span>Resume</span> </p> </li> <li> <p> <span>Terminate</span> </p> </li> </ul><br><br><br>Note that if you terminate an instance, this instance<br>will be deleted, while a suspended instance can still be<br>resumed. |
| Predicate | Select the instance(s) of which you need to change the status. The<br>options are:<br><br><ul> <li> <p> <span>Running instances</span>:											status of all the running instances will be											changed.</p> </li> <li> <p> <span>Instances in a specific												group</span>: status of the instances of a											specific instance group will be changed. You need to											enter the name of that group in the <span>Group name</span> field.</p> </li> <li> <p> <span>Running instances in a specific												group</span>: status of the running instances of											a specific instance group will be changed. You need to											enter the name of that group in the <span>Group name</span> field.</p> </li> <li> <p> <span>Instance with predefined												id</span>: status of a given instance will be											changed. You need to enter the ID of that instance in											the <span>Id</span> field. You can											find this ID on your Amazon EC2.</p> </li> </ul><br><br><br>An instance group is composed of the instances using<br>the same instance name you have defined in the Instance name field of tCloudStart. |
| Group name | Enter the name of the group in which you want to change the<br>status of given instances whose security group name or key pair name is set to<br>jclouds#&lt;$group\_name&gt; in the<br>tCloudStart component, where<br>&lt;$group\_name&gt; identifies the group to which the<br>instance belongs.<br><br>This field is available only when Instances in a<br>specific group or Running instances<br>in a specific group is selected from the Predicate list. |
| Id | Enter the ID of the instance of which you need to change the<br>status, for<br>instance, "${region}/${instance id}". This field appears when<br>you select Instance with predefined id<br>from the Predicate list. |

## Usage

| Usage guidance | Description |
| --- | --- |
| **Usage rule** | This component works standalone to change the status of given<br>instances on Amazon EC2. You can use this component to suspend,<br>resume or terminate the instance(s) you have deployed Jobs<br>on.<br><br>This component often works alongside tCloudStart to change the status of the instances<br>launched by the latter component. |
