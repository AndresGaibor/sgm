# tSQLTemplate

Executes the common database actions or customized SQL statement templates, for example to drop/create a table.

tSQLTemplate offers a range of SQL statement templates for a number of DBMSs to facilitate some of the most common database actions. These templates are accessible via the SQL Template view. Additionally, you are allowed to customize the SQL statement templates as needed.

## tSQLTemplate Standard properties

These properties are used to configure tSQLTemplate running in the Standard Job framework.

The Standard tSQLTemplate component belongs to the ELT family.

The component in this framework is available in all Talend products.
