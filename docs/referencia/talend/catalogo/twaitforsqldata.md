# tWaitForSqlData

Iterates on a given connection for insertion or deletion of rows and triggers a subJob when a condition linked to SQL data presence is met.

Information noteNote: This component cannot be used in ESB use cases.

## tWaitForSqlData Standard properties

These properties are used to configure tWaitForSqlData running in the Standard Job framework.

The Standard tWaitForSqlData component belongs to the Orchestration family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Wait at each iteration (in seconds) | Set the time interval in seconds between each check for the sql<br>data. |
| Max. iterations (infinite if empty) | Number of checks for sql data before the Jobs times out. |
| Use an existing connection/Component List | A connection needs to be open to allow the loop to check for sql<br>data on the defined DB.<br><br>When a Job contains the parent Job and the child Job,<br>Component list presents<br>only the connection components in the same Job level, so if you<br>need to use an existing connection from the other level, you<br>can<br><br>From the available database connection component in the level<br>where the current component is, select the Use or register a shared DB connection check<br>box. | Table to scan | Name of the table to be checked for insert or deletion |
| Trigger action when rowcount is | Select the condition to be met for the action to be carried<br>out:<br><br><br>Equal to<br>Not Equal to<br>Greater than<br>Lower than<br>Greater or equal to<br>Lower or equal to |

| --- | --- |
