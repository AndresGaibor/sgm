# tSVNLogInput

Retrieves the information of a specified revision or range of revisions from an SVN repository.

## tSVNLogInput Standard properties

These properties are used to configure tSVNLogInput running in the Standard Job framework.

The Standard tSVNLogInput component belongs to the Internet family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| URL | Type in the URL to the SVN repository to be accessed. |
| Need authentication? | Select this check box if authentication is needed to access the SVN<br>repository. |
| Username and Password | Enter the username and password to access the SVN repository if<br>authentication is needed.<br><br>To enter the password, click the [...] button<br>next to the password field, enter the password in double quotes in the pop-up dialog box,<br>and click OK to save the settings.<br><br>These two fields appear only when the Need<br>authentication? check box is selected. |
| From revision | Specify a start revision number of the revision range. |
| Only this revision | Select this check box if you need to retrieve the information of only the<br>revision specified in the From revision<br>field. |
| To revision | Specify an end revision number of the revision range. Enter *'HEAD'* for the latest revision.<br><br>This field disappears when the Only this<br>revision check box is selected. |
| Schema and Edit schema | A schema is a row description, it defines the fields to be processed and<br>passed on to the next component.<br><br>The schema of this component is read-only. It describes the properties of<br>the revision information. You can click the [...] button next to Edit<br>schema to view the predefined schema which contains the<br>following fields:<br><br><ul> <li> <p> <span>revision</span>: the revision number of                              the log message.</p> </li> <li> <p> <span>author</span>: the author who commits the                              log message.</p> </li> <li> <p> <span>date</span>: the date when the log                              message was committed.</p> </li> <li> <p> <span>message</span>: the content of the log                              message.</p> </li> <li> <p> <span>nb_file_added</span>: the number of added                              files.</p> </li> <li> <p> <span>nb_file_modified</span>: the number of                              modified files.</p> </li> <li> <p> <span>nb_file_deleted</span>: the number of                              deleted files.</p> </li> </ul> |
