# tRSSOutput

Creates and writes XML files that hold RSS or Atom feeds.

## tRSSOutput Standard properties

These properties are used to configure tRSSOutput running in the Standard Job framework.

The Standard tRSSOutput component belongs to the Internet family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| File name | Name or path to the XML file to be processed and/or the variable<br>to be used.<br><br>For further information about how to define and use a variable in a Job, see [Using contexts and variables](https://help.qlik.com/talend/r/en-US/8.0/studio-user-guide/contexts-and-variables). |
| Encoding | Select an encoding type from the list, or select Custom and define it manually. This field<br>is compulsory for DB data handling. |
| Append | Select this check box to add the new rows to the end of the<br>file. |
| Mode | Select between RSS or ATOM according to the feed you want to<br>generate. |
| Channel (in RSS mode) | Information noteNote:<br><br>The information to be typed in here concerns your entire input<br>data, site etc, rather than a particular item.<br><br><br>Title: Enter a meaningful<br>title.<br><br><br>Description: Enter a description<br>that you think will describe your content.<br><br><br>Publication date: Enter the<br>relevant date.<br><br><br>Link: Enter the relevant<br>URL. |
| Feed (in ATOM mode) | Title: Enter a meaningful<br>title.<br><br><br>Link: Enter the relevant<br>URL.<br><br><br>Id: Enter the valid URL<br>corresponding to the Link.<br><br><br>Update date: Enter the relevant<br>date .<br><br><br>Author name: Enter the relevant<br>name. |
| Optionnal Channel Elements | Click the [+] button below the table to add new lines and enter<br>the information relative to the RSS flow metadata:<br><br><br>Element Name: name of the metadata.<br><br><br>Element Value: content of the<br>metadata. |
| Schema and Edit<br>Schema | A schema is a row description, it defines the number of fields to be processed and<br>passed on to the next component. The schema is either Built-in or stored remotely in the<br>Repository.<br><br>Click Edit<br>schema to make changes to the schema. If the current schema is of the Repository type, three options are available:<br><br><ul> <li> <p> <span>View schema</span>: choose this                option to view the schema only.</p> </li> <li> <p> <span>Change to built-in property</span>:                choose this option to change the schema to <span>Built-in</span> for local changes.</p> </li> <li> <p> <span>Update repository connection</span>:                choose this option to change the schema stored in the repository and decide whether                to propagate the changes to all the Jobs upon completion.</p> <p>If you just want to                propagate the changes to the current Job, you can select <span>No</span> upon completion and choose this schema metadata                again in the <span>Repository Content</span>                window.</p> </li> </ul><br><br>By default, the schema of tRSSOutput is made of five read-only columns:<br>id, title, link,<br>updated, and summary. You can add new columns or click<br>Syn columns to retrieve the<br>schema structure from the preceding component. |
