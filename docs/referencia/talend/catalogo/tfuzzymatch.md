# tFuzzyMatch

Compares a column from the main flow with a reference column from the lookup flow and outputs the main flow data displaying the distance.

This component is not shipped with your Talend Studio by default. You need to install it using the Feature Manager. For more information, see [Installing features using the Feature Manager](https://help.qlik.com/talend/r/en-US/8.0/studio-user-guide/install-features-to-talend-studio).

## tFuzzyMatch Standard properties

These properties are used to configure tFuzzyMatch running in the Standard Job framework.

The Standard tFuzzyMatch component belongs to the Data Quality family.

The component in this framework is available in all Talend products.

| Matching type | Select the relevant matching algorithm among:<br><br><br>Levenshtein: Based on the edit<br>distance theory. It calculates the number of insertion, deletion or<br>substitution required for an entry to match the reference entry.<br><br><br>Metaphone: Based on a<br>phonetic algorithm for indexing entries by their pronunciation. It first loads<br>the phonetics of all entries of the lookup reference and checks all entries of<br>the main flow against the entries of the reference flow. It does not support Chinese characters.<br><br><br>Double Metaphone: a new<br>version of the Metaphone phonetic algorithm, that produces more accurate<br>results than the original algorithm. It can return both a primary and a<br>secondary code for a string. This accounts for some ambiguous cases as well as<br>for multiple variants of surnames with common ancestry. It does not support Chinese characters. |
| Min distance | (Levenshtein only) Set the minimum number of changes allowed to<br>match the reference. If set to 0, only perfect matches are returned. |
| Max distance | (Levenshtein only) Set the maximum number of changes allowed to<br>match the reference. |
| Matching column | Select the column of the main flow that needs to be checked<br>against the reference (lookup) key column |
| Unique matching | Select this check box if you want to get the best match possible,<br>in case several matches are available. |
| Matching item separator | In case several matches are available, all of them are displayed<br>unless the unique match box is selected. Define the delimiter<br>between all matches. |
