# tCombinedSQLAggregate

Provides a set of matrix based on values or calculations.

tCombinedSQLAggregate collects data values from one or more columns of a table for statistical purposes. This component has real-time capabilities since it runs the data transformation on the DBMS itself.

## tCombinedSQLAggregate Standard properties

These properties are used to configure tCombinedSQLAggregate running in the Standard Job framework.

The Standard tCombinedSQLAggregate component belongs to the ELT family.

The component in this framework is available in all Talend products.
