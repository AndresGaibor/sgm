# tAS400Output

Writes, updates, makes changes or suppresses entries in a database.

tAS400Output executes the action defined on the table and/or on the data contained in the table, based on the flow incoming from the preceding component in the Job.

## tAS400Output Standard properties

These properties are used to configure tAS400Output running in the Standard Job framework.

The Standard tAS400Output component belongs to the Databases family.

The component in this framework is available in all Talend products.

Information noteNote: This component is a specific version of a dynamic database connector. The properties related to database settings vary depending on your database type selection. For more information about dynamic database connectors, see [DB Generic components](https://help.qlik.com/talend/r/en-US/8.0/components/db-generic/db-generic-component).

## Usage

| Usage guidance | Description |
| --- | --- |
| **Usage<br>rule** | This component<br>offers the flexibility benefit of the DB query and covers all of the SQL<br>queries possible.<br><br>This<br>component must be used as an output component. It allows you to carry<br>out actions on a table or on the data of a table in a AS/400 database.<br>It also allows you to create a reject flow using a Row &gt; Rejects link<br>to filter data in error.
