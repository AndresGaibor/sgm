# tExasolCommit

Validates the data processed through the Job into the connected Exasol database.

Using a unique connection, this component commits in one go a global transaction instead of doing that on every row or every batch and thus provides gain in performance.

## tExasolCommit Standard properties

These properties are used to configure tExasolCommit running in the Standard Job framework.

The Standard tExasolCommit component belongs to the Databases family.

The component in this framework is available in all Talend products.

Information noteNote: This component is a specific version of a dynamic database connector. The properties related to database settings vary depending on your database type selection. For more information about dynamic database connectors, see [DB Generic components](https://help.qlik.com/talend/r/en-US/8.0/components/db-generic/db-generic-component).

| Close Connection | This check box is selected by default and<br>it allows you to close the database connection once the commit is done.<br>Clear this check box to continue to use the selected connection after<br>the component has performed its task.<br><br>Information noteWarning:<br><br><br>*If<br>you want to use a Row&gt;Main connection to link<br>tExasolCommit to your Job, your data will be<br>committed row by row. In this case, do not select the Close Connection<br>check box or your connection will be closed before the end of<br>your first row commit.* |
