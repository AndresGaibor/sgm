# tDotNETRow

Facilitates data transform by utilizing custom or built-in .NET classes.

tDotNETRow sends data to and from libraries and classes within .NET or other custom DLL files.

## tDotNETRow Standard properties

These properties are used to configure tDotNETRow running in the Standard Job framework.

The Standard tDotNETRow component belongs to the DotNET family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Schema and Edit<br>schema | <ul> <li>A schema is a row description, it defines the number of fields to be                  processed and passed on to the next component. The schema is either built-in or                  remotely stored in the Repository. </li> <li> <span>Built-in: </span>No property data stored                  centrally.</li> <li> <span>Repository</span>: Select the Repository file where                  properties are stored. The following fields are pre-filled in using fetched                  data</li> </ul> |
| Use a static method | Select this check box to invoke a static method in .NET and this will<br>disable Use an existing instance check box. |
| Propagate a data to output | Select this check box to propagate a transformed data to output. |
| Use an existing instance | Select this check box to reuse an existing instance of a .NET object from<br>the Existing instance to use list.<br><br>Existing instance to use: Select an<br>existing instance of .NET objects created by the other .NET components from the<br>list.<br><br>Information noteNote: This check box will be disabled if you have<br>selected Use a static method and<br>selecting this check box will disable Dll to<br>load, Fully qualified class<br>name(i.e. ClassLibrary1.NameSpace2.Class1) and Value(s) to pass to the<br>constructor. |
| Dll to load | Type in the path, or browse to the DLL library containing the class(es) of<br>interest or enter the assembly's name to be used. For example, *System.Data, Version=2.0.0.0, Culture=neutral,<br>PublicKeyToken=b77a5c561934e089* for an OleDb assembly. |
| Fully qualified class name(i.e.<br>ClassLibrary1.NameSpace2.Class1) | Enter a fully qualified name for the class of interest. |
| Method name | Fill this field with the name of the method to be invoked in .NET. |
| Value(s) to pass to the constructor | Click the plus button to add one or more lines for values to be passed to<br>the constructor for the object. Or, leave this table empty to call a default<br>constructor for the object.<br><br>The valid value(s) should be the<br>parameters required by the class to be used. |
| Method Parameters | Click the plus button to add one or more lines for parameters to be passed<br>to the method. |
| Output value target column | Select a column in the output row from the list to put value into<br>it. |

## Advanced settings

| Properties | Description |
| --- | --- |
| Create a new instance at each row | Select this check box to create a new instance at each row that passes<br>through the component. |
| Method doesn't return a value | Select this check box to invoke a method without returning a value as a<br>result of the processing. |
| Returns an instance of a .NET Object | Select this check box to return an instance of a .NET object as a result of<br>a invoked method. |
| Store the returned value for later use | Select this check box to store the returned value of a method for later<br>reuse in another tDotNETRow<br>component. |
| tStatCatcher Statistics | Select this check box to collect log data at the component level. |

## Usage

| Usage guidance | Description |
| --- | --- |
| **Usage rule** | This component is utilized to integrate with .NET objects.<br><br>To use this component, you must first install the runtime DLLs,<br>for example *janet-win32.dll* for Windows 32-bit version<br>and *janet-win64.dll* for Windows 64-bit version, from the<br>corresponding Microsoft Visual C++ Redistributable Package. This allows you to<br>avoid errors like the *UnsatisfiedLinkError* on dependent<br>DLL.<br><br>So ensure that the runtime and all of the other<br>DLLs which the DLL to be called depends on are installed and their versions are<br>consistent among one another.<br><br>Information noteNote:<br><br>The required DLLs can be installed in the *System32* folder or in the *bin* folder of the<br>Java runtime to be used. For users<br>of<br>Talend<br>solutions with ESB, to run a Job using this component in ESB<br>Runtime, you need to copy the runtime DLLs to the %KARAF\_HOME%/lib/wrapper/ directory. |
