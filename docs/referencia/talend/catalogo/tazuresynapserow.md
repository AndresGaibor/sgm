# tAzureSynapseRow

Executes an SQL query stated on an Azure Synapse Analytics database.

## tAzureSynapseRow Standard properties

These properties are used to configure tAzureSynapseRow running in the Standard Job framework.

The Standard tAzureSynapseRow component belongs to two families: Cloud and Databases.

The component in this framework is available in all Talend products.

## Advanced settings

| Properties | Description |
| --- | --- |
| Additional JDBC Parameters | Specify additional connection properties for the database<br>connection you are creating. The properties are separated by semicolon and<br>each property is a key-value pair. For example, *encrypt=true;trustServerCertificate=false;*<br>*hostNameInCertificate=\*.database.windows.net;loginTimeout=30;* for<br>Azure SQL database connection. |
| Authenticate using Azure Active<br>Directory | When selected, this option allows you to pick the authentication mode to use<br>from the Azure Active Directory authentication mode<br>dropdown list:<br><br><ul> <li> <span>Service principal (client secret)</span>: use the service                        principal credentials (client ID and client secret) to authenticate.</li> <li> <span>User password</span>: use the Azure Active Directory user                        credentials (username and password) to authenticate.</li> </ul><br><br>Read the Usage section of this document for<br>information about Microsoft SQL Server/JDBC encryption<br>requirements. |
| Propagate QUERY's recordset | Select this checkbox to insert the result of the query into a column of the<br>current flow. Select this column from the use column<br>list.<br><br>This option allows the component to have a different schema from that of the preceding component. Moreover, the column that holds the QUERY's recordset should be set to the type of Object and this component is usually followed by tParseRecordSet. |
| Use PreparedStatement | Select this checkbox if you want to query the database using a<br>PreparedStatement. In the Set PreparedStatement<br>Parameters table, define the parameters represented by "?" in<br>the SQL instruction of the Query field in the<br>Basic Settings tab.<br><br><ul> <li> <p> <span>Parameter Index</span>: Enter the parameter position in the SQL instruction.</p> </li> <li> <p> <span>Parameter Type</span>: Enter the parameter type.</p> </li> <li> <p> <span>Parameter Value</span>: Enter the parameter value.</p> </li> </ul><br><br>This option is very useful if you need to execute the same query several times. Performance levels are increased. |
| Commit every | Enter the number of rows to be completed before committing batches of rows<br>together into the database. This option ensures transaction quality (but not<br>rollback) and above all better performance on executions. |
| tStatCatcher Statistics | Select this checkbox to gather the Job processing metadata at the Job level<br>as well as at each component level. |

## Global Variables

| Variables | Description |
| --- | --- |
| NB\_LINE | The number of rows processed. This is an After variable and it returns an<br>integer.<br><br>Note that if the Propagate QUERY's recordset<br>option is selected in the Advanced settings view, this<br>variable returns the number of single ResultSet, which is<br>1. |
| ERROR\_MESSAGE | The error message generated by the component when an error<br>occurs. This is an After variable and it returns a string. |
| QUERY | The query statement being processed. This is a Flow variable<br>and it returns a string. |

## Usage

| Usage guidance | Description |
| --- | --- |
| Usage rules | This component offers the flexibility of the DB query and covers all possible SQL queries.<br><br>Information noteImportant: Microsoft SQL Server/JDBC encryption requirements<br><br>Starting with recent versions of the Microsoft SQL Server JDBC driver,<br>TLS encryption is enabled by default<br>(encrypt=true;trustServerCertificate=false). This<br>enhances security, but if your SQL Server does not support encrypted<br>connections or does not require clients to use TLS, you must set<br>encrypt=false in the JDBC parameters of this component<br>to connect successfully.<br><br><ul> <li> <p>For production or cloud environments using certificates signed by a                              trusted authority (e.g., Azure, AWS), no changes are needed, the                              default settings will work. </p> </li> <li> <p>For servers using self-signed certificates, use                                 <span>encrypt=true;trustServerCertificate=true</span> or                              specify the trust store details                                 (<span>encrypt=true;trustStore=&lt;your_trust_store&gt;;trustStorePassword=&lt;your_trust_store_password&gt;</span>).                           </p> </li> <li> <p>For non-secure development or test servers, set                                 <span>encrypt=false</span> in the additional JDBC parameters.                           </p> </li> </ul><br><br>For more information on how to use connections with encryption<br>properties, see [Microsoft SQL JDBC documentation](https://learn.microsoft.com/en-us/sql/connect/jdbc/connecting-with-ssl-encryption?view=sql-server-ver17). |
