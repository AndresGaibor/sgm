# tDropboxList

Lists the files stored in a specified directory on Dropbox.

## tDropboxList Standard properties

These properties are used to configure tDropboxList running in the Standard Job framework.

The Standard tDropboxList component belongs to the Cloud family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Use Existing Connection | Select this check box and in the Component<br>List drop-down list, select the desired connection component to<br>reuse the connection details you already defined. |
| Access Token | Enter the access token required by the Dropbox account you need to connect to.<br>This access token allows Talend Studio to make<br>Dropbox API calls for that Dropbox account.<br><br>Note that a Dropbox App should have been created under that account before generating the<br>access token. For further information about a Dropbox access token, see https://www.dropbox.com/developers/blog/94/generate-an-access-token-for-your-own-account. |
| Use HTTP Proxy | If you are using a proxy, select this check box and enter the host and port information of<br>that proxy in the corresponding fields that are displayed. |
| Path | Enter the path pointing to the folder you need to list the files<br>from, or enter the path pointing to the exact file you need to<br>read.<br><br>Note that the path string should start with a slash (/). It is the root folder of the<br>Dropbox App for which you are using the current access token. |
| List Type | Select the type of data you need to list from the specified<br>path. |
| Include subdirectories | Select this check box to list files from any existing sub-folders<br>in addition to the files in the directory defined in the Path field. |

## Global Variables

| Variables | Description |
| --- | --- |
| NAME | The name of the remote file being processed. This is a Flow variable and it<br>returns a string. |
| PATH | The path to the folder or the file being processed on Dropbox. This is a Flow<br>variable and it returns a string. |
| LAST\_MODIFIED | The timestamp of the last modification of the file being processed.<br>This is a Flow variable and it returns a long. |
| SIZE | The volume of the file being processed. This is a Flow variable and it returns a<br>long. |
| IS\_FILE | The boolean result of the file listing. This is a Flow variable and it<br>returns a boolean. The result Yes indicates that the listed data is of<br>the type File; otherwise, the type is Folder. |
| ERROR\_MESSAGE | The error message generated by the component when an error occurs. This<br>is an After variable and it returns a string. |
