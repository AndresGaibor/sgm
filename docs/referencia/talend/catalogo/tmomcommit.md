# tMomCommit

Commits data on the MQ Server.

tMomCommit commits in one go, using a unique connection, a global transaction instead of doing that on every row or every batch and thus provides gain in performance.

## tMomCommit Standard properties

These properties are used to configure tMomCommit running in the Standard Job framework.

The Standard tMomCommit component belongs to the Internet family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Component List | Select the Connection component used in your Job. |
| Close Connection | This check box is selected by default. It allows you to close the<br>database connection once the commit is done. Clear this check box to<br>continue to use the selected connection once the component has<br>performed its task.<br><br>Information noteWarning:<br><br><br>*If you want to use a Row<br>&gt;<br><br>Main<br>connection to link tMomCommit to your Job, your data will be<br>committed row by row. In this case, do not select the<br>Close connection check<br>box or your connection will be closed before the end of your<br>first row commit.* |
