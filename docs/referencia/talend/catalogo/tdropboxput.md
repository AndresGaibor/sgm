# tDropboxPut

Uploads data to Dropbox from either a local file or a given data flow.

## tDropboxPut Standard properties

These properties are used to configure tDropboxPut running in the Standard Job framework.

The Standard tDropboxPut component belongs to the Cloud family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Use Existing Connection | Select this check box and in the Component<br>List drop-down list, select the desired connection component to<br>reuse the connection details you already defined. |
| Access Token | Enter the access token required by the Dropbox account you need to connect to.<br>This access token allows Talend Studio to make<br>Dropbox API calls for that Dropbox account.<br><br>Note that a Dropbox App should have been created under that account before generating the<br>access token. For further information about a Dropbox access token, see https://www.dropbox.com/developers/blog/94/generate-an-access-token-for-your-own-account. |
| Use HTTP Proxy | If you are using a proxy, select this check box and enter the host and port information of<br>that proxy in the corresponding fields that are displayed. |
| Path (File Only) | Enter the path pointing to the file you need to write contents in.<br>This file will be created on the fly if it does not exist.<br><br>Note that the path string should start with a slash (/). It is the root folder of the<br>Dropbox App for which you are using the current access token. |
| Upload Mode | Select upload mode to be used:<br><br><ul> <li> <p> <span>Rename if Existing</span>:										the uploaded file is automatically renamed. For example, a										file named <em>test.txt</em> might be renamed										to <em>test (1).txt</em>.</p> </li> <li> <p> <span>Replace if Existing</span>:										the uploaded file replaces the existing one.</p> </li> <li> <p> <span>Update specified											Revision</span>: the file you are uploading is used										to update a specific revision of that file. If the revision										you specify is the latest revision, then the existing file										on Dropbox is replaced; if it is an older revision, the file										you are uploading is renamed to indicate that a conflict is										encountered; if the revision does not exist, an error is										returned.</p> </li> </ul> |
| Upload Incoming content as File | Select this radio button to read data directly from the input flow<br>of the preceding component and write the data into the file<br>specified in the Path field. |
| Schema and Edit schema | A schema is a row description. It defines the number of fields<br>(columns) to be processed and passed on to the next component. When you create a Spark<br>Job, avoid the reserved word line when naming the<br>fields.<br><br>Note that the schema of this component is read-only with a single<br>column named content and it<br>receives data from the *content*<br>column of its input schema only. This means that you must use a<br>*content* column in the input<br>data flow to carry the data to be uploaded. This type of column is<br>typically provided by the tFileInputRaw component. For further information,<br>see [tFileInputRaw](https://help.qlik.com/talend/en-US/components/8.0/raw/tfileinputraw).<br><br>The Schema field is not available<br>when you have selected the Expose as<br>OutputStream or the Upload<br>local file radio button. |
| Upload local file | Select this radio button to upload a locally stored file to<br>Dropbox. In the File field that is displayed, you need to enter the<br>path or browse to this file. |
| Expose as OutputStream | Select this check box to expose the output stream of this<br>component as a variable named OUTPUTSTREAM so that the other components can reuse<br>this variable to write the contents to be uploaded into the exposed<br>output stream.<br><br>For example, you can use the Use output<br>stream feature of the tFileOutputDelimited component to feed a given<br>tDropboxPut's exposed output<br>stream. For further information, see [tFileOutputDelimited](https://help.qlik.com/talend/en-US/components/8.0/delimited/tfileoutputdelimited). |
