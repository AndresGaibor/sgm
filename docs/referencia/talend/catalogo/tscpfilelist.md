# tSCPFileList

Lists files from the defined SCP server.

tSCPFileList iterates, over a fully encrypted channel, on files in a given directory on a remote host.

## tSCPFileList Standard properties

These properties are used to configure tSCPFileList running in the Standard Job framework.

The Standard tSCPFileList component belongs to the Internet family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Use an existing connection | Select this check box and in the Component<br>List drop-down list, select the desired connection component to<br>reuse the connection details you already defined.<br><br>Information noteNote: When a Job contains the parent Job and the child Job, do the following if you<br>want to share an existing connection between the parent Job and the child Job (for example,<br>to share the connection created by the parent Job with the child Job).<br><br><ol> <li>In the parent level, register the database connection to be shared               in the <span>Basic settings</span> view of the               connection component which creates that very database connection. </li> <li>In the child level, use a dedicated connection component to read               that registered database connection. </li> </ol><br><br>For an example about how to share a database connection across Job levels,<br>see [Sharing a database connection](https://help.qlik.com/talend/r/en-US/7.3/studio-user-guide/sharing-database-connection). |
| Host | Specify the host name or IP address of the SCP server. |
| Port | Specify the listening port number of the SCP server. |
| Username | Fill in the user name to access the SCP server. |
| Authentication method | Select one of the SCP authentication methods from the drop-down<br>list, Public key, Password, or Keyboard Interactive. |
| Password | Enter the password to access the SCP server.<br><br>To enter the password, click the [...] button<br>next to the password field, enter the password in double quotes in the pop-up dialog box,<br>and click OK to save the settings.<br><br>This field appears only when Password or Keyboard<br>Interactive is selected from the Authentication method drop-down<br>list. |
| Key Passphrase | Enter the passphrase for the public key.<br><br>To enter the passphrase, click the [...]<br>button next to the passphrase field, and then in the pop-up dialog box enter the passphrase<br>between double quotes and click OK to save the<br>settings.<br><br>This field appears only when Public<br>key is selected from the Authentication method drop-down list. |
| Private key | Browse to or type in the path to the private key.<br><br>This field appears only when Public<br>key is selected from the Authentication method drop-down list. |
| Command Separator | Specify the character used to separate multiple commands. |
| Filelist | Click the [+] button to add a<br>command or a set of commands to list files in a given directory on<br>the SCP server. |
