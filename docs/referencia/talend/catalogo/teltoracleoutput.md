# tELTOracleOutput

Performs the action (insert, update, delete, or merge) on data in the specified Oracle table through the SQL statement generated by the tELTOracleMap component.

The ELT Oracle components are closely related, in terms of their operating conditions. These components should be used to handle Oracle database table schemas to generate SQL statements, including clauses, which are to be executed in the database output table defined.

## tELTOracleOutput Standard properties

These properties are used to configure tELTOracleOutput running in the Standard Job framework.

The Standard tELTOracleOutput component belongs to the ELT family.

The component in this framework is available in all Talend products.

## Usage

| Usage guidance | Description |
| --- | --- |
| **Usage rule** | tELTOracleOutput is to be used along with the tELTOracleInput and tELTOracleMap components. Note that the Output link to be used with these components must correspond strictly to the syntax of the table name.<br><br>Information noteNote:<br><br>Note that the ELT components do not handle actual data flow but only schema information. |
