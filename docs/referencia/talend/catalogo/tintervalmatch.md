# tIntervalMatch

Returns a value based on a Join relation.

tIntervalMatch receives a main flow and aggregates it based on join to a lookup flow. Then it matches a specified value to a range of values and returns related information.

This component is not shipped with your Talend Studio by default. You need to install it using the Feature Manager. For more information, see [Installing features using the Feature Manager](https://help.qlik.com/talend/r/en-US/8.0/studio-user-guide/install-features-to-talend-studio).

## tIntervalMatch Standard properties

These properties are used to configure tIntervalMatch running in the Standard Job framework.

The Standard tIntervalMatch component belongs to the Data Quality family.

The component in this framework is available in all Talend products.
