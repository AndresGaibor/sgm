# tCombinedSQLFilter

Filters data by reorganizing, deleting or adding columns based on the source table and to filter the given data source using the filter conditions.

tCombinedSQLFilter allows you to alter the schema of a source table through column name mapping and to define a row filter on that table. Therefore, it can be used to filter columns and rows at the same time. This component has real-time capabilities since it runs the data filtering on the DBMS itself.

## tCombinedSQLFilter Standard properties

These properties are used to configure tCombinedSQLFilter running in the Standard Job framework.

The Standard tCombinedSQLFilter component belongs to the ELT family.

The component in this framework is available in all Talend products.
