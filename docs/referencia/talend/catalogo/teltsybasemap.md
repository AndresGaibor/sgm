# tELTSybaseMap

Builds the SQL SELECT statement using the table schema(s) provided by one or more tELTSybaseInput components.

The three ELT Sybase components are closely related, in terms of their operating conditions. These components should be used to handle Sybase database table schemas to generate SQL statements, including clauses, which are to be executed in the database output table defined.

## tELTSybaseMap Standard properties

These properties are used to configure tELTSybaseMap running in the Standard Job framework.

The Standard tELTSybaseMap component belongs to the ELT family.

The component in this framework is available in all Talend products.

| Usage guidance | Description |
| --- | --- |
| **Usage rule** | tELTSybaseMap is intended for use with<br>tELTSybaseInput and tELTSybaseOutput. Note that the Output<br>link to be used with these components must correspond strictly to the<br>syntax of the table name.<br><br>Information noteNote:<br><br>The ELT components only handle<br>schema information. They do not handle actual data flow. |
