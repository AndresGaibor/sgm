# tSocketOutput

Sends out the data from the incoming flow to a listening socket port.

The tSocketOutput component writes data to a listening port.

## tSocketOutput Standard properties

These properties are used to configure tSocketOutput running in the Standard Job framework.

The Standard tSocketOutput component belongs to the Internet family.

The component in this framework is available in all Talend products.

## Basic settings

| --- | --- |

| Compress | Select this check box to zip the data if relevant. |
