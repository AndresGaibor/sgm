# tSplitRow

Splits one input row into several output rows.

## tSplitRow Standard properties

These properties are used to configure tSplitRow running in the Standard Job framework.

The Standard tSplitRow component belongs to the Processing family.

The component in this framework is available in all Talend products.

| Properties | Description |

| Schema and<br>Edit Schema | <ul> <li> <p>A schema is a row description, it defines                                                  the number of fields to be processed and passed on                                                  to the next component.
