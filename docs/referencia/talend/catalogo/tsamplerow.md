# tSampleRow

Selects rows according to a list of single lines and/or a list of groups of lines.

tSampleRow filters rows according to line numbers.

## tSampleRow Standard properties

These properties are used to configure tSampleRow running in the Standard Job framework.

The Standard tSampleRow component belongs to the Processing family.

The component in this framework is available in all Talend products.
