# tParseRecordSet

Parses a recordset rather than individual records from a table.

The tParseRecordSet parses a set of records from a database table or DB query and possibly returns single records.

## tParseRecordSet Standard properties

These properties are used to configure tParseRecordSet running in the Standard Job framework.

The Standard tParseRecordSet component belongs to the Databases family.

The component in this framework is available in all Talend products.
