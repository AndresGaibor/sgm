# tS3Close

Shuts down a connection to Amazon S3, thus releasing the network resources.

## tS3Close Standard properties

These properties are used to configure tS3Close running in the Standard Job framework.

The Standard tS3Close component belongs to the Cloud family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Component List | List of connection components. |

## Advanced settings

| Properties | Description |
| --- | --- |
| tStatCatcher Statistics | Select this check box to collect log data at the component<br>level. |

## Global Variables

| Variables | Description |
| --- | --- |
