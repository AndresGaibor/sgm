# tUnite

Centralizes data from various and heterogeneous sources.

tUnite merges data from various sources, based on a common schema.

Note that tUnite cannot exist in a data flow loop. For instance, if a data flow goes through several tMap components to generate two flows, they cannot be fed to tUnite.

Information noteNote: This component is for sequential flow only and does not support parallelization.
