# tPivotToColumnsDelimited

Fine-tunes the selection of data to output.

The tPivotToColumnsDelimited outputs data based on a transpose operation carried out on a pivot column and the selected aggregation function.

## tPivotToColumnsDelimited Standard properties

These properties are used to configure tPivotToColumnsDelimited running in the Standard Job framework.

The Standard tPivotToColumnsDelimited component belongs to the File family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Pivot column | Select the column from the incoming flow that will be used as<br>pivot for the aggregation operation. |
| Aggregation column | Select the column from the incoming flow that contains the data to<br>be aggregated. |
| Aggregation function | Select the function to be used in case several values are<br>available for the pivot column. |
| Group by | <ul> <li> <p>Define the aggregation sets, the values of which will be used for								calculations.</p> </li> <li> <p> <span>Input Column</span>: Match the input								column label with your output columns, in case the output label of								the aggregation set needs to be different.</p> </li> </ul> |
| File Name | Name or path to the file to be processed and/or the variable to be<br>used.<br><br>For further information about how to define and use a variable in a Job, see [Using contexts and variables](https://help.qlik.com/talend/r/en-US/8.0/studio-user-guide/contexts-and-variables). |
| Field separator | Character, string or regular expression to separate fields of the<br>output file. |
| Row separator | String (ex: "\n"on Unix) to distinguish rows in the output<br>file. |
