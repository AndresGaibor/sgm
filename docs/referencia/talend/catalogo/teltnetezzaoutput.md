# tELTNetezzaOutput

Performs the action (insert, update, delete, or merge) on data in the specified Netezza table through the SQL statement generated by the tELTNetezzaMap component.

The three ELT Netezza components are closely related, in terms of their operating conditions. These components should be used to handle Netezza database table schemas to generate SQL statements, including clauses, which are to be executed in the database output table defined.

## tELTNetezzaOutput Standard properties

These properties are used to configure tELTNetezzaOutput running in the Standard Job framework.

The Standard tELTNetezzaOutput component belongs to the ELT family.

The component in this framework is available in all Talend products.
