# Creating context variables

Four context variables are used in this scenario: a4, b2, c9 and d6. These variables will set the name of the cells the tFixedFlowinput component will extract from the Excel file.

## Procedure

1. Select the Context view of your Job and click the [+] button to add four variables, a4, b1, c9 and d6.
2. In the Value field, under the Default context, enter the variable values, as follows.

   ![](https://help.qlik.com/talend/en-US/components/Resources/images/hqs1573040279633_LowRes.png)

   Information noteNote: The syntax to call a variable is context.VariableName.
3. Press Ctrl+S to save your changes.
