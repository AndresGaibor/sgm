# tELTVerticaOutput

Performs the action (insert, update or delete) on data in the specified Vertica table through the SQL statement generated by the tELTVerticaMap component.

The three ELT Vertica components are closely related, in terms of their operating conditions. These components should be used to handle Vertica database table schemas to generate SQL statements, including clauses, which are to be executed in the database output table defined.

## tELTVerticaOutput Standard properties

These properties are used to configure tELTVerticaOutput running in the Standard Job framework.

The Standard tELTVerticaOutput component belongs to the ELT family.

The component in this framework is available in all Talend products.
