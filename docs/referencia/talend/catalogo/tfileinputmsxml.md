# tFileInputMSXML

Reads the data structures (schemas) of a multi-structured XML file and sends the fields as defined in the different schemas to the next components using Row connections.

## tFileInputMSXML Standard properties

These properties are used to configure tFileInputMSXML running in the Standard Job framework.

The Standard tFileInputMSXML component belongs to the File and the XML families.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| File Name | Name of the file and/or the variable to be processed.<br><br>For further information about how to define and use a variable in a Job, see [Using contexts and variables](https://help.qlik.com/talend/r/en-US/8.0/studio-user-guide/contexts-and-variables).<br><br>Information noteWarning: Use absolute path (instead of relative path) for<br>this field to avoid possible errors. |
| Root XPath query | The root of the XML tree, which the query is based on. |
| Enable XPath in column "Schema XPath loop" but lose the<br>order | Select this check box if you want to define a XPath path in the<br>Schema XPath loop field of the<br>Outputs table while not keeping<br>the order of the data shown in the source XML file.<br><br>Information noteWarning:<br><br>This options takes effect only if you select the Dom4j generation mode in the<br>Advanced settings<br>view. |
| Outputs | Schema: Define as many schemas as<br>needed.<br><br><br>Schema XPath loop: Enter the node<br>of the XML tree or XPath path which the loop is based on.<br><br><br>XPath Queries: Enter the fields<br>to be extracted from the structured input.<br><br><br>Create empty row: Select this<br>check box if you want to create empty rows for the empty field(s) in<br>the schema. |
| Die on error | Select this check box to stop the execution of the Job when an<br>error occurs. Clear the check box to skip the row on error and<br>complete the process for error-free rows. |
