# tDenormalizeSortedRow

Synthesizes sorted input flow to save memory.

tDenormalizeSortedRow combines in a group all input sorted rows. Distinct values of the denormalized sorted row are joined with item separators.

## tDenormalizeSortedRow Standard properties

These properties are used to configure tDenormalizeSortedRow running in the Standard Job framework.

The Standard tDenormalizeSortedRow component belongs to the Processing family.

The component in this framework is available in all Talend products.
