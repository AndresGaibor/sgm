# tMysqlCommit

Commits in one go, using a unique connection, a global transaction instead of doing that on every row or every batch and thus provides gain in performance.

tMysqlCommit validates the data processed through the Job into the connected DB.

## tMysqlCommit Standard properties

These properties are used to configure tMysqlCommit running in the Standard Job framework.

The Standard tMysqlCommit component belongs to the Databases family.

The component in this framework is available in all Talend products.

Information noteNote: This component is a specific version of a dynamic database connector. The properties related to database settings vary depending on your database type selection. For more information about dynamic database connectors, see [DB Generic components](https://help.qlik.com/talend/r/en-US/8.0/components/db-generic/db-generic-component).

| --- | --- |
| Database | Select the desired database type from the list and click<br>Apply. |
| Component list | Select the tMysqlConnection<br>component in the list if more than one connection are planned for<br>the current job. |
| Close Connection | This check box is selected by default. It allows you to close the<br>database connection once the commit is done. Clear this check box to<br>continue to use the selected connection once the component has<br>performed its task.<br><br>Information noteWarning:<br><br><br>*If you want to use a Row<br>&gt;<br><br>Main<br>connection to link tMysqlCommit to your Job, your data will be<br>committed row by row. In this case, do not select the<br>Close connection check<br>box or your connection will be closed before the end of your<br>first row commit.* |

## Usage

| Usage guidance | Description |
| --- | --- |
| **Usage rule** | This component is more commonly used with other tMysql\*<br>components, especially with the tMysqlConnection and tMysqlRollback components. |
| Dynamic settings | Click the [+] button to add a row in the table<br>and fill the Code field with a context<br>variable to choose your database connection dynamically from multiple<br>connections planned in your Job.
