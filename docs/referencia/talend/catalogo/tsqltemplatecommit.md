# tSQLTemplateCommit

Commits a global action in one go using a single connection, instead of doing so for every row or every batch of rows separately. This provides a gain in performance.

tSQLTemplateCommit validates the data processed in a Job in a specified database.

## tSQLTemplateCommit Standard properties

These properties are used to configure tSQLTemplateCommit running in the Standard Job framework.

The Standard tSQLTemplateCommit component belongs to the ELT family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Database Type | Select the database type you want to connect to from the<br>list. |
| Component List | Select the ELT database connection component in the list if more<br>than one connection is required for the current Job. |
| Close Connection | Clear this check box to continue to use the selected connection<br>once the component has performed its task. |

## Advanced settings

| Properties | Description |
| --- | --- |
| tStatCatcher Statistics | Select this check box to gather the Job processing metadata at a<br>Job level as well as at each component level. |
