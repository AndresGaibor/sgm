# tSQLTemplateRollback

Cancels the transaction committed in the SQLTemplate database.

## tSQLTemplateRollback Standard properties

These properties are used to configure tSQLTemplateRollback running in the Standard Job framework.

The Standard tSQLTemplateRollback component belongs to the ELT family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Database Type | Select the database type you want to connect to from the<br>list. |
| Component List | Select the ELT database connection component in the list if more<br>than one connection is planned for the current Job. |
| Close Connection | Clear this check box to continue to use the selected connection<br>once the component has performed its task. |

## Advanced settings

| Properties | Description |
| --- | --- |
| tStatCatcher Statistics | Select this check box to gather the Job processing metadata at a<br>Job level as well as at each component level. |
