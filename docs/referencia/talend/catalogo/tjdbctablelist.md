# tJDBCTableList

Lists the names of a given set of JDBC tables using a select statement based on a Where clause.

tJDBCTableList iterates on a set of table names through a defined JDBC connection.

## tJDBCTableList Standard properties

These properties are used to configure tJDBCTableList running in the Standard Job framework.

The Standard tJDBCTableList component belongs to the Databases family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Database type | Select a database from the list, such as Mysql, Oracle,<br>etc. |
| Component list | Select the tJDBCConnection<br>component or a database-specific connection component if the<br>relevant database is selected from the Database type list. |

## Advanced settings

| Properties | Description |
| --- | --- |
| Use filter | Select this check box to filter the tables to be iterated<br>on. |
| Regular expression for tables<br>name | Enter the regular expression to identify table names.<br><br>Available when Use filter is<br>selected. |
| Filter criteria | Select the criteria for filtering table names.<br><br><br>Include: iterates on the table<br>names identified by the regular expression only.<br><br><br>Exclude: iterates on the table<br>names other than those identified by the regular expression.<br><br>Available when Use filter is<br>selected. |
| tStatCatcher Statistics | Select this check box to collect the log data at the component<br>level. |
