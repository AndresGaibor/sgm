# tSQSQueueList

Iterates and lists the URL of Amazon SQS (Simple Queue Service) queues in a specified region.

## tSQSQueueList Standard properties

These properties are used to configure tSQSQueueList running in the Standard Job framework.

The Standard tSQSQueueList component belongs to the Cloud family.

The component in this framework is available in all Talend products.

| Variables | Description |
| --- | --- |
