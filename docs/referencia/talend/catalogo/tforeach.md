# tForeach

Creates a loop on a list for an iterate link.

## tForeach Standard properties

These properties are used to configure tForeach running in the Standard Job framework.

The Standard tForeach component belongs to the Orchestration family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Values | Use the [+] button to add rows to<br>the Values table. Then click on the<br>fields to enter the list values to be iterated upon, between double<br>quotation marks. |

## Advanced settings

| Properties | Description |
| --- | --- |
| tStatCatcher Statistics | Select this check box to collect the log data at a component<br>level. |

This<br>variable functions only if the Die on error checkbox is<br>cleared, if the component has this checkbox.<br><br><br>CURRENT\_VALUE: the value currently iterated upon. This is a Flow<br>variable and it returns a string.<br><br>A Flow variable functions during the execution of a component<br>while an After variable functions after the execution of the component.<br><br>To fill up a field or expression with a variable, press Ctrl+Space to access the variable list and choose the variable to use from<br>it.<br><br>For more information about variables, see [Using contexts and variables](https://help.qlik.com/talend/r/en-US/8.0/studio-user-guide/contexts-and-variables). |
