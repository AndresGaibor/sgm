# tAzureSynapseOutput

Writes, updates, makes changes or suppresses entries in an Azure SQL Data Warehouse database.

## tAzureSynapseOutput Standard properties

These properties are used to configure tAzureSynapseOutput running in the Standard Job framework.

The Standard tAzureSynapseOutput component belongs to two families: Cloud and Databases.

The component in this framework is available in all Talend products.

## Usage

| Usage guidance | Description |
| --- | --- |
| Usage rules | This component is usually used as an end component of a Job or subJob and it<br>always needs an input link.<br><br>Information noteImportant: Microsoft SQL Server/JDBC encryption requirements<br><br>Starting with recent versions of the Microsoft SQL Server JDBC driver,<br>TLS encryption is enabled by default<br>(encrypt=true;trustServerCertificate=false). This<br>enhances security, but if your SQL Server does not support encrypted<br>connections or does not require clients to use TLS, you must set<br>encrypt=false in the JDBC parameters of this component<br>to connect successfully.<br><br><ul> <li> <p>For production or cloud environments using certificates signed by a                              trusted authority (e.g., Azure, AWS), no changes are needed, the                              default settings will work. </p> </li> <li> <p>For servers using self-signed certificates, use                                 <span>encrypt=true;trustServerCertificate=true</span> or                              specify the trust store details                                 (<span>encrypt=true;trustStore=&lt;your_trust_store&gt;;trustStorePassword=&lt;your_trust_store_password&gt;</span>).                           </p> </li> <li> <p>For non-secure development or test servers, set                                 <span>encrypt=false</span> in the additional JDBC parameters.                           </p> </li> </ul><br><br>For more information on how to use connections with encryption<br>properties, see [Microsoft SQL JDBC documentation](https://learn.microsoft.com/en-us/sql/connect/jdbc/connecting-with-ssl-encryption?view=sql-server-ver17). |
| Dynamic settings | Click the [+] button to add a row in the table<br>and fill the Code field with a context<br>variable to choose your database connection dynamically from multiple<br>connections planned in your Job. Within brackets are the<br>groups of parameters the number of which cannot exceed 2000, generally,<br>depending on the JBDC driver. Therefore, the batch size should be set so<br>that this limit is respected.<br><br>Note that some<br>features that are supported by other databases are not supported by<br>Azure Synapse Analytics.
