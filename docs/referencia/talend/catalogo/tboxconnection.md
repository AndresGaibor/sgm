# tBoxConnection (deprecated)

Availability-note[Deprecated](https://help.talend.com/r/en-US/Cloud/labels-on-talend-help-center/availability-deprecated)

This content is deprecated.

Creates a Box connection that the other Box components can reuse.

This component creates the connection to a given Box account.

## tBoxConnection Standard properties

Information noteDeprecation: This component is deprecated since Talend Studio 8.0 R2025-11 and removed from Talend Studio 8.0 R2026-09 onwards. Talend recommends you to migrate your Jobs to use the Box v2 components.

These properties are used to configure tBoxConnection running in the Standard Job framework.

The Standard tBoxConnection component belongs to the Cloud family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Client Key | Enter the client key required by Box to access the Box API. To obtain the client key and<br>client secret you need to create an account at https://developers.box.com/ and then create a Box App under the Box account to<br>be used. The client key and client secret can be obtained from the account application<br>settings. |
| Client Secret | Enter the client secret required by Box to access the Box API. To obtain the client key and<br>client secret you need to create an account at https://developers.box.com/ and then create a Box App under the Box account to<br>be used. The client key and client secret can be obtained from the account application<br>settings. |
| Access token | Enter the access token required by Box to access a Box account and operate it. For how to get<br>the access token and refresh token, check the Box documentation you can access from https://developers.box.com/. |
| Refresh Token | Enter the refresh token required by Box to refresh the access token automatically. For how to<br>get the access token and refresh token, check the Box documentation you can access from<br>https://developers.box.com/. |
| Use HTTP proxy | If you are using a proxy, select this check box and enter the host and port information of<br>that proxy in the corresponding fields that are displayed. |
