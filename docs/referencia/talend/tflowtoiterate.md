# tFlowToIterate

Reads data line by line from the input flow and stores the data entries in iterative global variables.

## tFlowToIterate Standard properties

These properties are used to configure tFlowToIterate running in the Standard Job framework.

The Standard tFlowToIterate component belongs to the Orchestration family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| Use the default (key, value) in global<br>variables | When selected, the system uses the default value<br>of the global variable in the current Job. |
| Customize | <ul> <li> <p> <span>key</span>: Type in a                                name for the new global variable. Press <span>Ctrl+Space</span> to access all available variables either                                global or user-defined.</p> </li> <li> <p> <span>value</span>: Click in                                the cell to access a list of the columns attached to the defined                                global variable.</p> </li> </ul> |

# Setting up the Job

## Procedure

1. Drop the following components from the Palette onto the design workspace: two tFileInputDelimited components, a tFlowToIterate, and a tLogRow.
2. Connect the first tFileInputDelimited to tFlowToIterate using a Row &gt; Main link, tFlowToIterate to the second tFileInputDelimited using an Iterate link, and the second tFileInputDelimited to tLogRow using a Row &gt; Main link.

   ![](https://help.qlik.com/talend/en-US/components/8.0/Resources/images/Use_Case_tFlowToIterate1.png)

# Configuring the Components

## Procedure

1. Double-click the first tFileInputDelimited to display its Basic settings view.
2. Click the [...] button next to the File Name field to select the path to the input file.

   Information noteNote:

   The File Name field is mandatory.

   ![](https://help.qlik.com/talend/en-US/components/8.0/Resources/images/Use_Case_tFlowToIterate2.png)

   The input file used in this scenario is *Customers.txt*. It is a text file that contains a list of names of three other simple text files: *Name.txt*, *E-mail.txt* and *Address.txt*. The first text file, *Name.txt*, is made of one column holding customers' names. The second text file, *E-mail.txt*, is made of one column holding customers' e-mail addresses. The third text file, *Address.txt*, is made of one column holding customers' postal addresses.

   Fill in all other fields as needed. For more information, see [tFileInputDelimited Standard properties](https://help.qlik.com/talend/en-US/components/8.0/delimited/tfileinputdelimited-standard-properties). In this scenario, the header and the footer are not set and there is no limit for the number of processed rows.
3. Click Edit schema to describe the data structure of this input file. In this scenario, the schema is made of one column, *FileName.*

   ![](https://help.qlik.com/talend/en-US/components/8.0/Resources/images/Use_Case_tFlowToIterate7.png)
4. Double-click tFlowToIterate to display its Basic settings view.

   ![](https://help.qlik.com/talend/en-US/components/8.0/Resources/images/Use_Case_tFlowToIterate3.png)

   Click the plus button to add new parameter lines and define your variables, and click in the key cell to enter the variable name as desired. In this scenario, one variable is defined: "Name\_of\_File".

   Alternatively, you can select the Use the default (key, value) in global variables check box to use the default in global variables.
5. Double-click the second tFileInputDelimited to display its Basic settings view.

   ![](https://help.qlik.com/talend/en-US/components/8.0/Resources/images/Use_Case_tFlowToIterate4.png)

   In the File name field, enter the directory of the files to be read, and then press Ctrl+Space to select the global variable *"Name\_of\_File"*. In this scenario, the syntax is as follows:
   ```
   "C:/scenario/flow_to_iterate/"+((String)globalMap.get("Name_of_File"))
   ```

   Click Edit schema to define the schema column name. In this scenario, it is *RowContent*.

   Fill in all other fields as needed. For more information, see [tFileInputDelimited Standard properties](https://help.qlik.com/talend/en-US/components/8.0/delimited/tfileinputdelimited-standard-properties).
6. In the design workspace, select the last component, tLogRow, and click the Component tab to define its basic settings.

   ![](https://help.qlik.com/talend/en-US/components/8.0/Resources/images/Use_Case_tFlowToIterate6.png)

   Define your settings as needed. For more information, see [tLogRow Standard properties](https://help.qlik.com/talend/en-US/components/8.0/logs-and-errors/tlogrow-standard-properties).

# Saving and executing the Job

## Procedure

1. Save your Job by pressing Ctrl+S.
2. Execute the Job by pressing F6 or clicking Run on the Run tab.

   ![](https://help.qlik.com/talend/en-US/components/8.0/Resources/images/Use_Case_tFlowToIterate5.png)

## Results

Customers' names, customers' e-mails, and customers' postal addresses appear on the console preceded by the schema column name.
