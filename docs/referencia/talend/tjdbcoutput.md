# tJDBCOutput

Executes the action defined on the data contained in the table, based on the flow incoming from the preceding component in the Job.

tJDBCOutput writes, updates, makes changes or suppresses entries in any type of database connected to a JDBC API.

This component can be used to write data to a RDS MariaDB, a RDS PostgreSQL or a RDS SQLServer database.

* [tJDBCOutput Standard properties](https://help.qlik.com/talend/en-US/components/8.0/jdbc/tjdbcoutput-standard-properties)
