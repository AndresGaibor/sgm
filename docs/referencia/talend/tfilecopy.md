# tFileCopy

Copies a source file or folder into a target directory.

## tFileCopy Standard properties

These properties are used to configure tFileCopy running in the Standard Job framework.

The Standard tFileCopy component belongs to the File family.

The component in this framework is available in all Talend products.

## Basic settings

| Properties | Description |
| --- | --- |
| File Name | Specify the path to the file to be copied.<br><br>This field does not appear when the Copy a directory check box is selected.<br><br>Information noteWarning: Use absolute path (instead of relative path) for<br>this field to avoid possible errors. |
| Copy a directory | Select this check box to copy a directory including all<br>subdirectories and files in it. |
| Source directory | Specify the source directory to copy.<br><br>This field appears only when the Copy a directory check box is selected.<br><br>Information noteWarning: Use absolute path (instead of relative path) for<br>this field to avoid possible errors. |
| Destination directory | Specify the directory to copy the source file or directory<br>to.<br><br>Information noteWarning: Use absolute path (instead of relative path) for<br>this field to avoid possible errors. |
| Rename | Select this check box if you want to rename the file copied to<br>the destination.<br><br>This field does not appear when the Copy a directory check box is selected. |
| Destination filename | Specify a new name for the file to be copied.<br><br>This field appears only when the Rename check box is selected. |
| Remove source file | Select this check box to move the source file to the<br>destination directory. This processor does not perform a copy operation, unless<br>you select the Force copy instead of move check box in<br>the Advanced settings.<br><br>This field does not appear when the Copy a directory check box is selected. |
| Replace existing file | Select this check box to overwrite any existing file with the<br>newly copied file.<br><br>This field does not appear when the Copy a directory check box is selected. |
| Create the directory if it doesn't<br>exist | Select this check box to create the specified destination<br>directory if it does not exist.<br><br>This field does not appear when the Copy a directory check box is selected. |

## Advanced settings

| Properties | Description |
| --- | --- |
| Force copy instead of move | Select this option to perform a copy operation instead of the default move<br>operation.<br><br>This field appears only when the Remove source file<br>check box is selected. |
| Preserve last modified time | Select this option to use the last modified time of the source file as that of<br>the destination file.<br><br>If this option is not selected, the current OS behavior for last modified time<br>is adopted. |
| tStatCatcher Statistics | Select this check box to gather the Job processing metadata at<br>a Job level as well as at each component level. |

# Moving/copying/renaming files in batch

This scenario shows the way for moving, copying, and renaming files in a directory in batch.

Two components are used for this purpose: tFileList and tFileCopy. The tFileList component iterates the files in the directory and passes the information about each of the files (such as filename and file path) to the tFileCopy component; the tFileCopy component moves, copies, or renames the files one by one using the information received from the tFileList component. ![Job with tFileList and tFileCopy.](https://help.qlik.com/talend/en-US/components/8.0/Resources/images/Use_Case_tFileCopy1.png)

## Procedure

1. Create a new Job and add a tFileList component and a tFileCopy component by typing their names in the design workspace or dropping them from the Palette.
2. Connect tFileList to tFileCopy using a Row &gt; Iterate link.
3. Double-click tFileList to open its Basic settings view.

   ![Basic settings view for tFileList.](https://help.qlik.com/talend/en-US/components/8.0/Resources/images/Use_Case_tFileCopy2.png)
4. In the Directory field, browse to or type in the directory (D:/Input in this example) to iterate upon.
5. Double-click tFileCopy to open its Basic settings view.

   ![Basic settings view for tFileCopy.](https://help.qlik.com/talend/en-US/components/8.0/Resources/images/Use_Case_tFileCopy3.png)
6. In the File Name field, press Ctrl+Space to access the global variable list and select the tFileList\_1.CURRENT\_FILEPATH variable from the list to fill the field with ((String)globalMap.get("tFileList\_1\_CURRENT\_FILEPATH")).
7. Set the destination directory by browsing to the directory or type in the path to the directory in the Destination directory field.
8. Perform one of the following operations.
   * To move the files, select the Remove source file check box, leave other options as they are.
   * To copy the files, make sure the Remove source file check box is not selected, leave other options as they are.
   * To rename the files, make sure the destination directory is the current directory of the files, select the Rename option, type in the new filenames for the files in the Destination filename field, and then select the Remove source file option. The example given in the following figure renames the files by prefixing the filenames with the string renamed\_.

   ![Basic settings operations.](https://help.qlik.com/talend/en-US/components/8.0/Resources/images/rename_files.png)
9. Press Ctrl+S to save your Job and press F6 to execute it.

   You can check the files moved or copied in the destination directory or check the renamed files in the source directory.
